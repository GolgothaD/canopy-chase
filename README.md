# Canopy Chase

A jungle-ruins maze chase for phones. Play here: **https://golgothad.github.io/canopy-chase/**

Steer a hungry monkey through overgrown temple mazes, eating seeds while four jungle predators hunt you: the Jaguar (stalker), Viper (ambusher), Croc (flanker), and Gorilla (wildcard). A golden banana turns the tables for a few seconds. Swipe anywhere, use the on-screen D-pad, or play with an Xbox controller (stick/D-pad to move, A select, B back, Menu pause, View settings). On Android, open it in Chrome and pick "Add to Home screen" to install it as an app. It works offline too.
